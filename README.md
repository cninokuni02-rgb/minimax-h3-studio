# MiniMax H3 Cloud Studio

เว็บแอปพลิเคชันสำหรับสร้างวิดีโอ AI อัจฉริยะด้วย MiniMax H3 (Ref2VA) บน RunPod RTX 4090 (ComfyUI) พร้อมระบบควบคุมประหยัดค่าใช้จ่ายและตัดเงินอัตโนมัติ

## ฟีเจอร์หลัก
1. ควบคุมและตัดค่าไฟได้ 100%:
   - มีปุ่ม "หยุดเซิร์ฟเวอร์ (ตัดค่าไฟ)" บนหน้าเว็บ กดปุ๊บหยุดคิดเงินค่า GPU ($0.74/ชม.) ทันที ข้อมูลโมเดลไม่หาย
   - Auto-Stop: ติ๊กถูกให้หยุดเครื่องเซิร์ฟเวอร์อัตโนมัติเมื่อวิดีโอเรนเดอร์เสร็จสิ้น
   - ตรวจสอบยอดเงินคงเหลือในบัญชี RunPod และคำนวณค่าใช้จ่ายตามเวลาจริง
2. ใช้งานง่าย สไตล์ Studio UI:
   - ลากวางภาพใบหน้าคน, ภาพหน้าจอ/ฉาก, และไฟล์เสียงพากย์
   - ระบบ Preset สคริปต์ภาษาไทยสำหรับทำคลิปรีวิวคอม, ผู้ประกาศข่าว, หรือวิดีโอสอนโปรแกรม
   - ตัวเล่นวิดีโอแบบพรีวิวในตัว พร้อมปุ่มดาวน์โหลด .mp4
3. พร้อม Deploy หรือ Push ขึ้น GitHub:
   - พัฒนาด้วย FastAPI + Modern Tailwind CSS (Dark Mode)
   - ไม่ต้องติดตั้ง Node.js หรือ build step ให้ยุ่งยาก

## วิธีการติดตั้งและรันใช้งาน
1. ติดตั้ง Dependencies:
   pip install -r requirements.txt
2. รันแอปพลิเคชัน:
   ดับเบิลคลิกไฟล์ run.bat
   หรือรัน: python -m uvicorn backend.main:app --host 127.0.0.1 --port 8989 --reload
3. เปิดบราวเซอร์ไปที่: http://localhost:8989
